
# Executive Summary

This project demonstrates a structured approach to cybersecurity risk governance using sample risk data, SQL analysis and a Power BI dashboard file.

The project focuses on identifying cybersecurity risks, assessing their likelihood and impact, calculating risk scores and documenting mitigation measures.

It also includes SQL queries that demonstrate incident analysis, severity reporting and risk prioritisation.

The project illustrates how business analytics concepts can support cybersecurity risk visibility and management decision-making.

**Scope:** This is an educational portfolio project using illustrative data. It is not a deployed enterprise platform or a live security monitoring system.
